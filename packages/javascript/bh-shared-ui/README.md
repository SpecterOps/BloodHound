# bh-shared-ui

## Storybook

From the `bhce` workspace, run `yarn workspace bh-shared-ui storybook` to preview the
`AppIcon` and `ConfirmationDialog` stories at http://localhost:6006.

Run `yarn workspace bh-shared-ui build:storybook` to generate a static site in
`packages/javascript/bh-shared-ui/storybook-static`.
